| Method       | Purpose           |
| ------------ | ----------------- |
| `push()`     | add end           |
| `pop()`      | remove end        |
| `shift()`    | remove first      |
| `unshift()`  | add first         |
| `splice()`   | add/remove/change |
| `slice()`    | copy portion      |
| `includes()` | check value       |
| `indexOf()`  | find index        |
| `join()`     | convert to string |
