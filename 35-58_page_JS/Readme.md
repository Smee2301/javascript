Operator is special symbol used to perform opration on operands (Value and variables);
Types :
1.Arithmetic : +,-,*,/,%,++,--
2.Assignment : =,+=,-=,*=, /=, %=
3.Comparison : >,<,<=,>=,!==,===,!=,==
4.Logical : && , || , ! 
5.Bitwise : &,|,^,~ 
6.ternary : con ? "true" : "false";
7.Type Operators : typeof(Checks data type), instanceof (Checks object type)
